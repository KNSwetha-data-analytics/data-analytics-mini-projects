# Data Dictionary - Sample Superstore Dataset

## Ship Mode
Shipping mode used for order delivery.

Possible values:
- Same day
- First class
- Second class
- Standard class

## Segment
Customer segment placing the order.

Possible values
- Customer
- Corporate
- Home Office

## Country
Country where the orders are placed.

Possible values
- United States

## City
City where the order was placed.

 531 unique possible values

## State
State where the order was placed.

49 unique possible values

## Postal Code
Postal Code associated with the order location.

## Region
Geographical region of sales.

Possible values
- Central
- South
- West
- East

## Category
High-level product category.

Possible values
- Furniture
- Office Supplies
- Technology

## Sub-Category
Detailed product classification under each category.

## Sales
Revenue generated from sales.

## Quantity
Number of units sold.

## Discount
Discount % applied to the sale.

## Profit
Profit earned from the transaction
Positive values - Profit
Negative values - Loss
